# Markdown Organizer v1.3.0

이번 릴리즈는 앱 런타임을 Electron에서 Tauri 2로 옮긴 마이그레이션 릴리즈입니다. React 기반 화면은 유지하면서 파일 시스템, SQLite, 검색, 파일 감시, 윈도우 제어를 Rust/Tauri 백엔드로 이전했습니다.

## 주요 변경

- Electron main/preload 런타임을 제거하고 `src-tauri` Rust 백엔드로 전환했습니다.
- 기존 렌더러의 `window.api` 호출은 Tauri command/event 어댑터로 연결해 UI 흐름을 유지했습니다.
- GitHub Actions 빌드/릴리즈 워크플로를 제거했습니다.
- 릴리즈는 로컬에서 빌드한 산출물을 GitHub Release에 업로드하는 방식으로 변경했습니다.
- macOS 릴리즈 자산은 `.app.zip`, `.dmg`, `SHA256SUMS` 구성으로 제공합니다.

## 수정 사항

- 상단바 빈 영역 드래그로 창 이동이 되지 않던 문제를 수정했습니다.
- 앱 재시작 시 마지막 프로젝트/문서/폴더 펼침 상태/스크롤 위치가 복원되지 않던 문제를 수정했습니다.
- 파일을 여러 개 오갈 때 각 파일별 스크롤 위치가 독립적으로 유지되도록 저장 방식을 변경했습니다.
- 우측 상단 빠른 테마 변경 버튼을 제거하고, 폴더 이동 버튼을 우측 상단에 유지했습니다.

## 데이터와 호환성

- 새 앱은 Tauri 앱 데이터 디렉터리에 SQLite 데이터를 저장합니다.
- 프로젝트 상태 테이블에 `scroll_positions` 컬럼을 추가합니다. 기존 DB가 있으면 앱 시작 시 자동으로 컬럼을 추가합니다.
- 파일별 스크롤 위치는 JSON 형태로 저장되며, 기존 단일 `scrollPos` 값도 계속 유지됩니다.

## 설치 메모

- macOS 빌드는 Apple Developer ID 공증이 없는 로컬 빌드입니다.
- 첫 실행 시 Gatekeeper가 차단하면 시스템 설정의 개인정보 보호 및 보안에서 허용하거나, 신뢰할 수 있는 GitHub Release 다운로드에 한해 `xattr -cr`를 사용할 수 있습니다.
